## 1. Objectives and prerequisites

By the end of this lesson you should be able to do seven things without looking at notes. First, define what a discrete random variable is and distinguish it from a continuous random variable. Second, build the probability distribution of a discrete random variable from a random experiment. Third, compute the expected value (mean) of a discrete random variable and interpret it as the long-run average. Fourth, compute the variance and standard deviation of a discrete random variable. Fifth, apply the linearity properties of expected value and the variance of independent variables. Sixth, recognize the Bernoulli distribution as a special case and understand its link to the binomial distribution. Seventh, interpret expected value in real decisions (games of chance, insurance, investment).

The prerequisites are the previous probability lesson (sample space, event, conditional probability, multiplication rule), plus summation notation (σ), fractions, and percentages. You need to operate with weighted sums and understand that a probability is a weight between 0 and 1.

Entry check, thirty seconds. You roll a fair die and win as many euros as the number shown. How much do you expect to win per roll on average? If you answered (1+2+3+4+5+6)/6 = 3.5 euros, you are ready. If you answered 3 or 4 euros (the median or the mode), you confuse mean with expected value. Review the idea of weighted average before continuing.

A note on scope. Expected value is not what "most likely" happens in a single trial, but the average over many trials. In a single die roll you will not get 3.5 euros, but in a thousand rolls the average will approach 3.5.

## 2. Why it matters

Expected value is the tool that turns probability into decision. A casino does not bet on one concrete spin; it bets that, over thousands of spins, its expected value is positive. An insurer does not know whether you will have an accident, but knows how much premium to charge so that its expected value is positive. An investor does not know whether a stock will rise, but compares the expected value of different options.

It also matters because expected value and variance are the building blocks of inferential statistics. The sample mean is an estimator of the population expected value; the standard error depends on the variance; confidence intervals and hypothesis tests are built on these concepts. Without understanding expected value and variance, you cannot understand why a larger sample reduces uncertainty.

And there is a practical reason: expected value protects you from irrational decisions under uncertainty. Understanding that a lottery has negative expected value helps you avoid spending money on it; understanding that insurance has negative expected value for you (but positive for the insurer) helps you decide whether to buy it.

## 3. Intuition

Imagine a roulette wheel with three pockets: 1, 2, and 3, each with probability 1/3. If you spin and win as many euros as the number that comes up, how much do you expect to win on average? You do not win exactly 1, 2, or 3 euros; you win a mixture. The weighted average is (1×1/3) + (2×1/3) + (3×1/3) = 6/3 = 2 euros. That 2 is the expected value: it is not a possible result in one spin, but it is the average your winnings approach if you repeat the experiment many times.

An extreme case. If the wheel has a single pocket with number 7 (probability 1), the expected value is 7×1 = 7. If all pockets give 0, the expected value is 0. Expected value always lies between the minimum and maximum possible values.

Another image: the center of gravity. Imagine a light bar with weights placed at the possible values, where the weight of each value is its probability. The expected value is the point where the bar balances exactly. Values with more probability pull the center of gravity more strongly toward themselves.

An important warning: expected value does not predict an individual outcome. If the expected value of a game is +0.5 euros, it does not mean you will win 0.5 euros in the next game; it means that, after many games, your average winnings tend to 0.5 euros. In a single game you can win a lot, lose a lot, or tie.

One last intuition before the formal definition: expected value is linear even when the variables are not independent. This means E(X+Y) = E(X) + E(Y) always, regardless of whether X and Y are related. This property is surprisingly powerful because it lets you compute expected values of complex sums without needing to know the full joint distribution.

## 4. Definition and notation

**Random variable.** A function that assigns a number to each outcome of a random experiment. If X is a random variable, X(ω) is the numeric value associated with outcome ω.

**Discrete random variable.** A random variable that takes a finite (or countable) number of values. Examples: the number of heads in 3 coin tosses ({0,1,2,3}), the result of a die ({1,…,6}), the number of customers arriving in an hour ({0,1,2,…}).

**Continuous random variable.** A random variable that can take any value in an interval. Examples: a person's height, waiting time, package weight. This lesson focuses on the discrete case; the continuous case requires integral calculus and is covered later.

**Probability distribution of a discrete variable.** The list of all possible values x₁, x₂, …, xₙ of X together with their probabilities P(X = xᵢ). It must satisfy: 0 ≤ P(X = xᵢ) ≤ 1 for all i, and the sum of all probabilities is 1: Σ P(X = xᵢ) = 1.

$$P(X = x_i) = p_i, \qquad \sum_{i=1}^{n} p_i = 1$$

**Expected value (mean) of a discrete variable.** The weighted average of the possible values, where the weights are the probabilities:

$$E(X) = \sum_{i=1}^{n} x_i \cdot P(X = x_i) = x_1p_1 + x_2p_2 + … + x_np_n$$

**Variance of a discrete variable.** Measures how much the values disperse around the expected value:

$$Var(X) = E\big((X - E(X))^2\big) = \sum_{i=1}^{n} (x_i - E(X))^2 \cdot P(X = x_i)$$

**Standard deviation.** The square root of the variance:

$$\sigma_X = \sqrt{Var(X)}$$

**Alternative variance formula.** An equivalent and often easier form is:

$$Var(X) = E(X^2) - [E(X)]^2 = \sum_{i=1}^{n} x_i^2 p_i - \left(\sum_{i=1}^{n} x_i p_i\right)^2$$

**Linearity of expected value.** For any two random variables X and Y (independent or not) and constants a, b:

$$E(aX + bY) = a \cdot E(X) + b \cdot E(Y)$$

**Variance of the sum of independent variables.** If X and Y are independent:

$$Var(X + Y) = Var(X) + Var(Y)$$

This property does NOT hold if X and Y are dependent; then you must add the covariance term: Var(X+Y) = Var(X) + Var(Y) + 2·Cov(X,Y).

**Bernoulli variable.** A discrete random variable that takes value 1 with probability p (success) and 0 with probability 1−p (failure). Its expected value is E(X) = p and its variance is Var(X) = p(1−p). It is the elementary block of the binomial distribution, covered in the next lesson.

## 5. Step-by-step derivation

### Step 1. List the possible values of X
Identify all outcomes of the experiment and the numeric value the random variable assigns to each one.

### Step 2. Assign the probability to each value
For each value xᵢ, compute P(X = xᵢ). Make sure all probabilities are ≥ 0 and sum to 1.

### Step 3. Build the distribution table
Write two columns: value xᵢ and probability pᵢ. This table is the complete probability distribution of X.

### Step 4. Compute the expected value
Multiply each value by its probability and sum: E(X) = Σ xᵢ·pᵢ.

### Step 5. Compute E(X²)
Multiply each squared value by its probability and sum: E(X²) = Σ xᵢ²·pᵢ. You need this for the variance.

### Step 6. Compute the variance
Apply Var(X) = E(X²) − [E(X)]². Or equivalently, compute each (xᵢ − E(X))²·pᵢ and sum.

### Step 7. Compute the standard deviation
σ_X = √Var(X). This is in the same units as X, which makes it more interpretable than variance.

### Step 8. Interpret
Expected value is the long-run average; standard deviation is the "typical error" around that average.

**Derivation of the alternative formula Var(X) = E(X²) − [E(X)]².** Starting from the definition:
Var(X) = E((X − E(X))²) = E(X² − 2X·E(X) + [E(X)]²).
By linearity of expected value:
Var(X) = E(X²) − 2E(X)·E(X) + [E(X)]² = E(X²) − 2[E(X)]² + [E(X)]² = E(X²) − [E(X)]².
This identity is useful because it avoids computing deviations (xᵢ − E(X)) one by one.

## 6. Worked examples

**Example 1. Fair die.** You roll a fair die and X is the result. Possible values are 1, 2, 3, 4, 5, 6, each with probability 1/6.

| xᵢ | pᵢ |
|---|---|
| 1 | 1/6 |
| 2 | 1/6 |
| 3 | 1/6 |
| 4 | 1/6 |
| 5 | 1/6 |
| 6 | 1/6 |

E(X) = (1+2+3+4+5+6)/6 = 21/6 = 3.5.
E(X²) = (1+4+9+16+25+36)/6 = 91/6 ≈ 15.167.
Var(X) = 91/6 − (3.5)² = 91/6 − 12.25 = 15.167 − 12.25 = 2.917.
σ_X = √2.917 ≈ 1.71.
Interpretation: in a single roll you do not get 3.5, but over many rolls the average approaches 3.5 and results typically deviate about 1.71 from that mean.

**Example 2. Red-or-black bet on a simplified roulette.** A roulette has 18 red pockets, 18 black pockets, and 1 green (zero). You bet 1 euro on red: if red comes up, you net +1 euro (you receive 2, you staked 1); otherwise you lose 1 euro. Let X be the net gain. X = +1 with probability 18/37, X = −1 with probability 19/37.

| xᵢ | pᵢ |
|---|---|
| +1 | 18/37 ≈ 0.486 |
| −1 | 19/37 ≈ 0.514 |

E(X) = 1×(18/37) + (−1)×(19/37) = −1/37 ≈ −0.027 euros.
Interpretation: on average you lose 2.7 cents per bet. That is the house edge. E(X²) = 1²×(18/37) + (−1)²×(19/37) = 1. Var(X) = 1 − (−1/37)² ≈ 0.999. σ_X ≈ 1 euro.

**Example 3. Bernoulli variable (coin toss).** X = 1 if heads, X = 0 if tails, with p = 0.5.

E(X) = 1×0.5 + 0×0.5 = 0.5.
E(X²) = 1²×0.5 + 0²×0.5 = 0.5.
Var(X) = 0.5 − (0.5)² = 0.5 − 0.25 = 0.25.
σ_X = √0.25 = 0.5.
For a biased coin with p = 0.8 (toward heads): E(X) = 0.8, Var(X) = 0.8×0.2 = 0.16, σ_X = 0.4. The closer p is to 0 or 1, the lower the variance (the outcome is more predictable).

**Example 4. Two dice, sum.** You roll two dice and X is the sum. Values range from 2 to 12 with different probabilities. The full distribution:

| xᵢ | pᵢ |
|---|---|
| 2 | 1/36 |
| 3 | 2/36 |
| 4 | 3/36 |
| 5 | 4/36 |
| 6 | 5/36 |
| 7 | 6/36 |
| 8 | 5/36 |
| 9 | 4/36 |
| 10 | 3/36 |
| 11 | 2/36 |
| 12 | 1/36 |

E(X) = (2×1 + 3×2 + 4×3 + 5×4 + 6×5 + 7×6 + 8×5 + 9×4 + 10×3 + 11×2 + 12×1)/36 = 252/36 = 7.
This makes sense: the most likely sum is 7 and the distribution is symmetric around 7.
Var(X) = E(X²) − 49. E(X²) = (4×1 + 9×2 + 16×3 + 25×4 + 36×5 + 49×6 + 64×5 + 81×4 + 100×3 + 121×2 + 144×1)/36 = 1974/36 = 54.833.
Var(X) = 54.833 − 49 = 5.833. σ_X ≈ 2.42.

**Example 5. Assembly line (realistic data).** A machine produces parts; the number of defective parts in a batch of 100 follows this distribution:

| Defective parts X | Probability |
|---|---|
| 0 | 0.70 |
| 1 | 0.20 |
| 2 | 0.08 |
| 3 | 0.02 |

E(X) = 0×0.70 + 1×0.20 + 2×0.08 + 3×0.02 = 0 + 0.20 + 0.16 + 0.06 = 0.42 defective parts per batch.
E(X²) = 0×0.70 + 1×0.20 + 4×0.08 + 9×0.02 = 0 + 0.20 + 0.32 + 0.18 = 0.70.
Var(X) = 0.70 − (0.42)² = 0.70 − 0.1764 = 0.5236.
σ_X = √0.5236 ≈ 0.72.
Interpretation: on average there are 0.42 defective parts per batch (just under 1), with a standard deviation of 0.72.

## 7. Errors and misinterpretations

### Error 1. Confusing expected value with most likely result
The expected value of a die is 3.5, which is not even a possible result. The most likely result (mode) of a die is indistinguishable: all have the same probability. Expected value is a weighted average, not a prediction of the next trial.

### Error 2. Believing expected value holds in a single trial
If E(X) = 3.5 for a die, in a single roll you will never get 3.5. The law of large numbers says the average of many rolls approaches 3.5, not that each roll is 3.5.

### Error 3. Adding variances of dependent variables
Var(X+Y) = Var(X) + Var(Y) only if X and Y are independent. If they are dependent (for example, the number of men and the number of women in a fixed-size group), you must add the covariance term. Adding variances without checking independence underestimates or overestimates the real dispersion.

### Error 4. Confusing variance with standard deviation
Variance is in squared units (euros², persons²), while standard deviation is in the same units as X (euros, persons). Do not compare a variance directly with a standard deviation.

### Error 5. Forgetting that probabilities must sum to 1
When building a distribution, if the probabilities do not sum to 1, the calculation of E(X) and Var(X) makes no sense. Always check Σ pᵢ = 1 as the first step.

## 8. Connections and transfer

Expected value and variance connect directly with inferential statistics. The sample mean is an estimator of the population expected value; the standard error of the mean is σ/√n, which depends on the population standard deviation; confidence intervals and hypothesis tests are built on these concepts. Without understanding expected value and variance, you cannot understand why a larger sample reduces uncertainty.

They also connect with decision-making under uncertainty: in finance, expected value compares investment opportunities; in insurance, the premium is set so the insurer's expected value is positive; in project management, expected value helps choose among options with different outcomes and probabilities.

In data science and machine learning, the loss function (for example, mean squared error) is motivated by minimizing the expected value of squared error, and standard deviation appears in feature scaling and model diagnostics.

The most useful transfer is the habit of deciding by expected value rather than by most likely result or anecdote. Instead of choosing the option that "probably" works, compare the expected value of each alternative weighted by its probabilities.

A final bridge: the Bernoulli variable of this lesson is the elementary block of the binomial distribution (successes in n independent trials), developed in the next lesson. Mastering E(X) and Var(X) of Bernoulli will let you understand the binomial with no extra effort.

## 9. Practice and summary

1. You roll a fair die and X is the result. What is E(X)? — **Solution:** E(X) = (1+2+3+4+5+6)/6 = 21/6 = 3.5.

2. A random variable X takes value 2 with probability 0.3, value 5 with probability 0.5, and value 8 with probability 0.2. What is E(X)? — **Solution:** E(X) = 2×0.3 + 5×0.5 + 8×0.2 = 0.6 + 2.5 + 1.6 = 4.7.

3. Using the variable from exercise 2, what is Var(X)? — **Solution:** E(X²) = 4×0.3 + 25×0.5 + 64×0.2 = 1.2 + 12.5 + 12.8 = 26.5. Var(X) = 26.5 − 4.7² = 26.5 − 22.09 = 4.41. σ_X = √4.41 = 2.1.

4. You bet 2 euros on a number in a simplified roulette of 37 pockets: if you hit, you net 70 euros; if you miss, you lose 2 euros. What is the expected value? — **Solution:** X = +70 with p = 1/37, X = −2 with p = 36/37. E(X) = 70×(1/37) + (−2)×(36/37) = (70 − 72)/37 = −2/37 ≈ −0.054 euros. On average you lose 5.4 cents per bet.

5. A coin is biased: p(heads) = 0.7. Let X = 1 if heads, 0 if tails. What are E(X) and Var(X)? — **Solution:** E(X) = 0.7. Var(X) = p(1−p) = 0.7×0.3 = 0.21. σ_X = √0.21 ≈ 0.458.

6. You roll two independent dice and X is the sum. Using linearity, what is E(X)? — **Solution:** Each die has E = 3.5. By linearity, E(X) = E(die1) + E(die2) = 3.5 + 3.5 = 7. (Matches example 4 in section 6.)

**Map of five ideas.** First: a discrete random variable takes countable values with a probability distribution whose probabilities sum to 1. Second: expected value is the weighted average E(X) = Σ xᵢ·pᵢ and represents the long-run average. Third: variance measures dispersion around the expected value, Var(X) = E(X²) − [E(X)]², and standard deviation is its square root. Fourth: expected value is linear, E(aX+bY) = aE(X)+bE(Y), and the variance of the sum of independent variables is the sum of the variances. Fifth: expected value does not predict an individual outcome, but the average over many trials.

**Final self-check.** If you can explain without looking why the expected value of a die is 3.5 although 3.5 is not a possible result, why Var(X) = E(X²) − [E(X)]² is equivalent to the definition of variance, and why the expected value of a roulette bet can be negative although in a single spin you can win, then you master this lesson. If any of the three sends you back, review the corresponding example.
