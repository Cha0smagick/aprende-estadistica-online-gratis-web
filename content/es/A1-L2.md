## 1. Objetivos y prerrequisitos

Al terminar esta lección deberías poder clasificar cualquier variable en cualitativa o cuantitativa, y dentro de cada tipo, en nominal, ordinal, discreta o continua. En concreto: distinguir etiquetas de cantidades, decidir si una variable es contable o medible, reconocer códigos numéricos que no son números y saber qué operaciones tienen sentido con cada tipo. También deberías poder explicar por qué calcular la media de un código postal es un error.

Los prerrequisitos son la población y la muestra, las proporciones y las operaciones básicas. No necesitas estadística avanzada. Si entiendes que «rojo» y «azul» son etiquetas y que «3 goles» es una cantidad, ya tienes la distinción principal.

Autochequeo de entrada, treinta segundos. ¿La nota A/B/C/D es un número? Si respondiste «no, es una categoría ordenada», estás listo. Si respondiste «sí, porque se puede ordenar», confundes orden con cantidad. La nota tiene orden, pero la distancia entre A y B no está definida. Esa diferencia decide qué estadísticos puedes usar.

Un aviso de alcance. Esta lección clasifica variables, no decide qué análisis hacer. La clasificación es el primer paso: una variable mal clasificada lleva a un estadístico inválido. La media de categorías, la suma de códigos o la desviación de un ranking son errores que parecen cálculos y no lo son.

## 2. Por qué importa

El tipo de variable determina qué operaciones tienen sentido. Con una cualitativa nominal solo puedes contar frecuencias y modas; con una ordinal, además, medianas y percentiles; con una cuantitativa, medias, desviaciones y diferencias. Ignorar el tipo produce números que no significan nada, aunque la aritmética sea correcta.

También importa porque los datos llegan codificados. Un cuestionario puede guardar «hombre=1, mujer=2»; una base de datos puede usar «0/1» para sí/no. Esos números son etiquetas, no cantidades. Si el analista no lo sabe, calcula una media de 1,5 y la interpreta como «una persona y media», que es absurdo. La codificación es una convención de almacenamiento, no una licencia para operar.

En machine learning, el tipo de variable decide el preprocesamiento: las categóricas se codifican con one-hot o embeddings; las numéricas se escalan. Tratar una categórica como numérica introduce un orden falso; tratar una ordinal como nominal pierde información. La clasificación no es teoría: es una decisión de modelado que afecta a las predicciones. Un modelo puede fallar no por el algoritmo, sino por haber codificado mal una columna.

Y hay una razón práctica: la mayoría de los errores de interpretación en informes vienen de mezclar tipos. Una media de códigos, una correlación con categorías sin codificar o una regresión con una variable nominal sin dummies producen resultados que no se sostienen. La clasificación es el control de calidad previo.

## 3. Intuición

### Etiquetas y cantidades

Una variable cualitativa asigna etiquetas: color, género, marca, ciudad. Una cuantitativa asigna cantidades: altura, edad, ingresos, número de hijos. La etiqueta no se suma; la cantidad sí. La imagen clave es la de un cajón de etiquetas frente a una regla: puedes ordenar etiquetas por un criterio, pero no medir distancias entre ellas sin una escala.

### Discreta y continua

Una variable cuantitativa es discreta si sus valores son contables y separados: número de hijos, goles, clics. Es continua si puede tomar cualquier valor en un intervalo: altura, tiempo, temperatura. La distinción es una idealización: una altura se mide con precisión finita, pero el modelo subyacente es continuo. Para el análisis, lo importante es si tiene sentido interpolar entre valores.

### Códigos

Un código es un número que representa una etiqueta. El 1 y el 2 de «hombre/mujer» no indican que mujer sea el doble de hombre; solo identifican categorías. La media de códigos no tiene interpretación. Si necesitas un número para modelar, usa una codificación que respete el tipo (dummies para nominal, valores ordenados para ordinal) y declara la transformación.

### Cuántas categorías

El número de categorías afecta al análisis. Una nominal con dos categorías es binaria y se codifica con una dummy; con k categorías, se necesitan k−1 dummies para evitar colinealidad. Una ordinal con muchas categorías puede tratarse como cuasi-continua si se justifica, pero no por comodidad. La decisión de agrupar categorías debe preservar el significado y reportarse.

### El problema de los códigos

El problema de los códigos es que parecen números y invitan a operar con ellos. Un identificador de cliente, un código postal o un código de producto se almacenan como enteros, pero no representan cantidades. Sumarlos o promediarlos produce números que no describen nada. La solución es tratar la columna como categórica y, si se modela, codificarla con dummies. La misma lógica se aplica a los números de teléfono: tienen dígitos, pero no son cantidades.

### Variables compuestas

Una variable compuesta combina varias en un índice: un test de calidad de vida, una puntuación de riesgo, un índice de precios. Su tipo depende de cómo se construyó. Si suma ítems ordinales, el resultado es una escala compuesta que se trata como cuasi-continua, con la justificación explícita. Si combina categorías, sigue siendo categórica. La construcción debe documentarse para que el tipo no sea una caja negra.

## 4. Definición y notación

### Cualitativas

- **Nominal:** categorías sin orden. Color, género, ciudad, marca. Solo igualdad y conteo.
- **Ordinal:** categorías con orden, sin distancia definida. Talla S/M/L, nota A/B/C, satisfacción baja/media/alta. Mediana y percentiles tienen sentido; la media es discutible.

### Cuantitativas

- **Discreta:** valores contables, normalmente enteros. Número de hijos, goles, accidentes. Se puede contar y, a veces, promediar.
- **Continua:** valores en un intervalo, medidos con una unidad. Altura, peso, tiempo, temperatura. Se puede promediar y calcular desviaciones.

| Tipo | Subtipo | Ejemplo | Operaciones típicas |
|---|---|---|---|
| Cualitativa | Nominal | Color | Conteo, moda |
| Cualitativa | Ordinal | Talla | Mediana, percentiles |
| Cuantitativa | Discreta | Nº de hijos | Media, conteo |
| Cuantitativa | Continua | Altura | Media, desviación |

### Variables de intervalo y razón

Dentro de las cuantitativas, la escala puede ser de intervalo (cero arbitrario, como °C) o de razón (cero verdadero, como kg). Esa distinción se estudia en la lección siguiente; aquí basta con saber que no todas las cuantitativas permiten decir «el doble».

### Variables derivadas

Una variable derivada se construye a partir de otras: IMC=peso/altura², edad en años, tasa de conversión. Su tipo depende de la operación: un cociente de dos continuas es continuo; un conteo de éxitos es discreto. Declarar la fórmula evita interpretaciones erróneas.

## 5. Derivación paso a paso

### Clasificar una variable

**Paso 1. ¿Es una etiqueta o una cantidad?** Si los valores son nombres o códigos, es cualitativa. **Paso 2. ¿Hay orden?** Si las categorías se ordenan, es ordinal; si no, nominal. **Paso 3. Si es cantidad, ¿se cuenta o se mide?** Contar da discreta; medir da continua. **Paso 4. ¿El cero es real?** Si sí, razón; si no, intervalo. **Paso 5. Comprueba.** ¿La operación que quieres hacer tiene sentido con ese tipo?

### Operaciones válidas

**Paso 6. Nominal.** Conteo, proporciones, moda. No media, no mediana. **Paso 7. Ordinal.** Conteo, mediana, percentiles; la media es una convención discutible. **Paso 8. Discreta.** Conteo, media, varianza; cuidado con los ceros. **Paso 9. Continua.** Media, varianza, intervalos. **Paso 10. Verifica.** Si la operación no respeta el tipo, el resultado es una ficción.

### Codificar sin destruir el tipo

**Paso 11. Nominal.** Usa dummies (0/1) o códigos con etiquetas; no interpretes el código como cantidad. **Paso 12. Ordinal.** Conserva el orden; si usas números, declara que son rangos. **Paso 13. Discreta.** Conserva los enteros; no inventes decimales. **Paso 14. Continua.** Conserva la unidad y la precisión.

### Por qué la media de un ordinal es discutible

La media requiere que las distancias entre valores tengan sentido. En una escala A/B/C, la distancia entre A y B no está definida; asignar 1/2/3 impone una distancia arbitraria. La mediana solo usa el orden y es más robusta. En escalas Likert de 1 a 5, la práctica de promediar es común, pero se justifica si se asume que las distancias son aproximadamente iguales; sin ese supuesto, la media es una convención, no una medida.

### Operaciones y gráficos

El tipo de variable también decide el gráfico. Las nominales se muestran con barras o tartas; las ordinales, con barras ordenadas; las discretas, con barras o puntos; las continuas, con histogramas o densidades. Usar un histograma para categorías o una tarta para una continua es una señal de que el tipo no se entendió. El gráfico debe respetar la estructura del dato, no solo decorarlo.

## 6. Ejemplos resueltos

### Videojuegos

**Ejemplo 1. FIFA.** Posición (POR/DEF/MED/DEL) es nominal; estrellas de skill (1–5) es ordinal; goles es discreta; altura es continua. **Ejemplo 2. Partida.** Número de kills es discreta; tiempo jugado es continua; personaje elegido es nominal; rango (bronce/plata/oro) es ordinal.

### Salud

**Ejemplo 3. Pacientes.** Grupo sanguíneo es nominal; gravedad (leve/moderada/grave) es ordinal; número de ingresos es discreta; presión arterial es continua. **Ejemplo 4. Síntomas.** Presencia/ausencia es nominal; intensidad en una escala 1–10 es ordinal o cuasi-intervalo, según el uso; temperatura es continua.

### Un caso con datos

**Ejemplo 5. Encuesta.** Sexo (nominal), nivel educativo (ordinal), ingresos (continua), número de hijos (discreta). Si el formulario guarda sexo como 1/2, la media 1,5 no significa nada; es un código. **Ejemplo 6. Código postal.** Es nominal: identifica una zona, no una cantidad. Ordenar por código postal no es ordenar por riqueza ni por distancia.

### La trampa

**Ejemplo 7. Media de códigos.** Calcular la media de género (1/2) y reportar 1,5 es un error de tipo. Detección: el resultado no tiene interpretación. Corrección: usa frecuencias o dummies. **Ejemplo 8. Media de ordinales.** Promediar una escala A/B/C como 1/2/3 es una convención extendida, pero la distancia entre A y B no está definida. Detección: se trata el ordinal como intervalo. Corrección: usa mediana o moda, o justifica la convención.

**Ejemplo 9. El código de producto.** Un sistema guarda productos con códigos 100, 200, 300. La media de códigos es 200, pero no significa nada: los códigos identifican, no miden. Detección: el número no cambia si se reordena el catálogo. Corrección: trata la columna como nominal y usa frecuencias.

**Ejemplo 10. La talla de camiseta.** S/M/L es ordinal. Puedes decir que M es mayor que S, pero no que la diferencia S–M es igual a M–L. La mediana tiene sentido; la media de códigos 1/2/3 es una convención. Si necesitas una medida continua, usa el perímetro de pecho en cm, que sí es cuantitativa.

**Ejemplo 11. La nota de corte.** Una universidad publica notas de corte 5,0; 7,5; 11,2. Son cuantitativas continuas y se pueden promediar, pero el promedio de notas de corte de carreras distintas no describe a ningún estudiante. El tipo es correcto; la interpretación del agregado, no. La clasificación evita errores de tipo, no errores de pregunta.

**Ejemplo 12. El índice de satisfacción.** Un cuestionario con 5 ítems de 1 a 5 se suma en un índice de 5 a 25. El índice es una escala compuesta; tratarla como continua es una convención habitual, pero la distancia entre 5 y 6 no es la misma que entre 24 y 25. Se reporta como puntuación, no como una medida física.

## 7. Errores y malinterpretaciones

### Los errores que más cuestan

**Error 1. Tratar códigos como cantidades.** Detección: media de identificadores. Corrección: usa frecuencias. **Error 2. Promediar ordinales sin justificar.** Detección: se asume que la distancia entre categorías es igual. Corrección: mediana o moda.

**Error 3. Confundir discreta con cualitativa.** Detección: un conteo se trata como categoría. Corrección: si se cuenta, es cuantitativa discreta. **Error 4. Confundir continua con discreta.** Detección: se interpola entre valores que no existen. Corrección: respeta la naturaleza de la variable.

**Error 5. Olvidar la unidad.** Detección: una altura sin cm o m. Corrección: declara la unidad. **Error 6. Crear una variable derivada sin declararla.** Detección: no se sabe cómo se calculó. Corrección: documenta la fórmula.

**Error 7. Tratar una ordinal como continua.** Detección: se calculan diferencias o desviaciones en una escala sin distancias. Corrección: usa métodos para ordinales o justifica la escala.

**Error 8. Agrupar categorías sin criterio.** Detección: la categoría «otros» esconde un grupo grande. Corrección: conserva las categorías relevantes o documenta la agrupación.

**Error 9. Confundir el tipo con el formato.** Un número guardado como texto sigue siendo un número; una etiqueta guardada como entero sigue siendo una etiqueta. Detección: el formato de la celda se confunde con la naturaleza del dato. Corrección: clasifica por significado, no por apariencia.

## 8. Conexiones y transferencia

El tipo de variable conecta con las escalas de medición, los estadísticos descriptivos y el modelado. También con la visualización: un gráfico de barras para nominales, un histograma para continuas, un boxplot para cuantitativas. Usar el gráfico equivocado es otra forma de ignorar el tipo.

En machine learning, la codificación de variables es una decisión de diseño. En encuestas, el tipo determina qué preguntas se pueden resumir. En salud, distingue un síntoma presente/ausente de una presión arterial. En economía, un código de sector no es una cantidad. La clasificación es el primer control de calidad de cualquier análisis, y también el primero que se olvida cuando los datos ya vienen en una hoja de cálculo. Revisar el tipo de cada columna antes de calcular es una rutina barata que evita errores caros, sobre todo cuando los datos vienen de fuentes distintas y se han pegado juntos sin revisar encabezados, unidades ni códigos de valores faltantes que parecen datos reales, como el 0 o el −1, que el software interpretará como cantidades y promediará sin avisar, como si fueran observaciones válidas y no códigos de ausencia que el software no distingue de un cero real ni de un valor imposible que puede sesgar todos los cálculos posteriores y las conclusiones que se saquen de ellos, a menudo sin que nadie lo note hasta que el resultado final es absurdo y alguien pregunta por qué el promedio de los códigos no significa absolutamente nada para nadie que lea el informe y confíe en la cifra sin preguntar de dónde sale ni qué codifica cada número en la hoja.

Una transferencia directa: si una tabla tiene una columna «nivel» con valores 1, 2 y 3, pregunta si son categorías ordenadas o cantidades. Si son categorías, la media no es interpretable; si son cantidades, sí. La respuesta cambia el análisis. Y si el código 1 significa «bajo» y el 3 «alto», el orden importa, pero la distancia no está definida.

2. Número de hermanos: ¿tipo? — **Solución:** Cuantitativa discreta.
3. Altura: ¿tipo? — **Solución:** Cuantitativa continua.
4. Nota A/B/C: ¿tipo? — **Solución:** Cualitativa ordinal.
5. Código postal: ¿tipo? — **Solución:** Cualitativa nominal.
6. ¿Se puede promediar un código postal? — **Solución:** No; es una etiqueta.
7. ¿Qué operaciones permiten las nominales? — **Solución:** Conteo, proporciones y moda.
8. ¿Qué operaciones permiten las continuas? — **Solución:** Media, varianza, intervalos.

**Mapa de cinco ideas.** Primera: cualitativa = etiqueta; cuantitativa = cantidad. Segunda: nominal sin orden; ordinal con orden. Tercera: discreta se cuenta; continua se mide. Cuarta: los códigos no son cantidades. Quinta: el tipo decide qué operaciones tienen sentido.
